# Dota 2 Telegram Bot & Pro Tracker Analytics

Автоматический бот и аналитическая веб-платформа для Dota 2 в стиле Dota2ProTracker. Проект собирает глубокие данные сыгранных матчей через OpenDota API (включая внутриигровой чат, позиционку, тайминги покупок и порядок прокачки способностей), проводит разбор микро- и макро-игры с помощью модели Google Gemini 3.8 Flash, публикует ежедневные постироничные посты в Telegram-канал и автоматически обновляет интерактивный сайт на GitHub Pages.

## Возможности

- **Сбор глубоких логов матчей**: интеграция с OpenDota API с автоматическим запросом на парсинг реплеев (`/request/{match_id}`).
- **Внутриигровой чат**: сохранение и отображение полной истории реплик матча (All-chat и союзный чат) с фиксацией колов, бахвальства и тильта.
- **Позиционка и смерти**: фиксация мест гибели, ключевых файтов и причин смертей.
- **Билды и тайминги**: матрица прокачки способностей с 1 по 30 уровень и таймлайн покупок предметов с точностью до минуты.
- **ИИ-тренер Gemini 3.8 Flash**:
  - Структурированный разбор ошибок для каждой игры на сайте (диагноз, клоун-рейтинг из 1000, анализ позиционки, айтемизации и чата).
  - Сводный постироничный пост для Telegram-канала с обзором дня и ссылкой на сайт.
- **Веб-платформа Dota2ProTracker**: современный темный интерфейс на GitHub Pages с фильтрами по героям и исходам матчей.
- **100% бесплатный запуск**: полностью автоматизировано через GitHub Actions с деплоем на GitHub Pages.

## Переменные окружения

Для работы бота через GitHub Actions или локально требуются переменные:

| Переменная | Описание |
|---|---|
| `TG_BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `TG_CHANNEL_ID` | ID канала или чата (например, `@channel_name` или `-100...`) |
| `GOOGLE_API_KEY` | Ключ доступа к Google Gemini API |
| `DOTA_ACCOUNT_ID` | 32-битный цифровой ID игрока в Dota 2 |
| `SITE_URL` | Ссылка на сайт GitHub Pages (по умолчанию https://danislonzombovich.github.io/dota-tg-bot/) |

## Локальный запуск

1. Установка зависимостей:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Запуск сбора статистики и генерации аналитики:
```bash
export TG_BOT_TOKEN="your_token"
export TG_CHANNEL_ID="your_channel_id"
export GOOGLE_API_KEY="your_api_key"
export DOTA_ACCOUNT_ID="your_dota_id"
python bot.py
```

3. Локальный просмотр веб-сайта:
```bash
python -m http.server 8080 -d web
```
Откройте в браузере `http://localhost:8080`.

## Автоматизация и GitHub Actions

Workflow в `.github/workflows/bot.yml` запускается ежедневно по расписанию в 17:00 UTC, а также поддерживает запуск вручную через кнопку Run workflow в Actions. После завершения анализа свежие данные сохраняются в репозиторий, а сайт пересобирается и деплоится на GitHub Pages.
